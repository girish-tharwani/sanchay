# Feature Plan

When this skill is invoked, follow these instructions exactly. Do NOT write any code.

1. Read and understand the requirements provided by the user.
2. Ask clarifying questions if anything is ambiguous or underspecified.
3. Once requirements are clear, explain your implementation plan:
   - Which files will be touched and why
   - What new classes, methods, or fields will be added
   - Any data model changes (e.g. new fields in JSON, new enum values)
   - Any UI changes (new screens, dialogs, columns, badges)
   - Any edge cases or tricky parts you anticipate
4. Wait for the user to confirm the plan before doing anything.

Do not write, edit, or create any source files until the user explicitly says to proceed.
